🧩 수련생 정보 항목 관리

「수련생 관리 → 수련생 등록」의 입력칸을 늘리거나 줄이는 설정입니다. 필요 없는 항목은 [숨기기], 다시 쓰려면 [표시]를 누르세요. 저장된 학생 데이터는 그대로 유지됩니다.

✏️ 기존 항목 수정

아래 수련생 등록 화면에 나오는 입력칸을 직접 편집합니다. 이름 변경, 순서 ↑↓, 표시/숨김으로 칸을 줄이거나 늘릴 수 있습니다. 이름·출석번호는 필수입니다. 변경 후 맨 아래 저장을 누르세요.

➕ 입력칸 추가 / 제거

🔐 관리자 보안 설정

최초 등록은 현재 관리자 비밀번호로 확인한 후 진행합니다. 이후에는 현재 비밀번호를 입력하여 변경할 수 있습니다. 새 비밀번호는 4자 이상으로 설정하세요.

먼저 등록 상태 확인을 누른 다음, 현재 비밀번호와 새 비밀번호를 입력해 주세요.

안전 보호: 출결·수련생 관리 외 도장 설정 등 모든 관리자 서버 기능의 인증 호환성을 확인한 후 비밀번호 등록을 활성화합니다.

🔗 네 가지 주소 관리

학부모에게는 학부모 확인 주소 또는 설치 주소만 전달하세요. 관리자 주소는 관리자 전용입니다.

📅 월별 출석부

기존 출석번호와 터치 출석 기록을 통합해 표시합니다. ○는 출석한 날입니다. A4 가로 인쇄 또는 PDF 저장이 가능합니다.

조회할 연월을 선택하세요.

✅ 사범님 터치 출석체크
